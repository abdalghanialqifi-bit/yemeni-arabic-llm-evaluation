# Evaluation Rubric

Score each dimension from 1 (poor) to 5 (excellent).

| Dimension | 1 | 3 | 5 |
|---|---|---|---|
| Dialect authenticity | Clearly inappropriate | Plausible but uncertain | Natural for stated context |
| Semantic accuracy | Meaning wrong | Partially correct | Meaning preserved |
| Contextual understanding | Ignores context | Mostly fits | Precisely fits |
| Cultural relevance | Inappropriate | Neutral/uncertain | Appropriate |
| Naturalness | Unnatural/textbook-like | Understandable | Conversational |
| Grammar/morphology | Serious errors | Minor issues | Appropriate |
| Intent preservation | Intent changed | Partially preserved | Fully preserved |

Failure categories: `MSA_OVER_DIALECT`, `WRONG_DIALECT`, `SEMANTIC_DRIFT`, `CONTEXT_MISS`, `CULTURAL_MISMATCH`, `OVERGENERALIZATION`, `REGISTER_MISMATCH`, `GRAMMAR_MORPHOLOGY`, `OTHER`.

Every score below 5 should have concise evidence.
