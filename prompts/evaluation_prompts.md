# Evaluation Prompts

## General evaluator
Evaluate an LLM response for a Yemeni Arabic task. Score dialect authenticity, semantic accuracy, context, cultural appropriateness, naturalness, grammar/morphology, and intent preservation from 1–5. Identify failure categories and give evidence for scores below 5.

Do not assume one expression is universal across Yemen. If region is unspecified, distinguish between plausible and universal usage.

## Failure analysis
Document: model response, required intent, exact mismatch, failure category, and a better response only when the correction is defensible. Flag regional uncertainty instead of inventing certainty.
